# Hi, I'm PCHardwareTest 👋

I'm building simple browser-based tools for testing and troubleshooting PC hardware.

## 🔧 PCHardwareTest

**PCHardwareTest** is a free online PC hardware testing toolkit that lets users check common hardware directly from a web browser without installing additional software.

The project includes browser-based tools for:

* Keyboard testing
* Mouse testing
* Microphone testing
* Speaker and headphone testing
* Webcam testing
* Screen and display testing
* Gamepad testing
* Touchscreen testing
* Touchpad and pointer testing
* Battery information
* Network information
* System information

🌐 **Website:** https://pchardwaretest.com/

⌨️ **Online Keyboard Test:** https://pchardwaretest.com/keyboard-test-online/

## 🚀 Project Focus

I'm interested in building practical browser-based tools that make PC troubleshooting easier and more accessible.

The goal is to keep hardware testing transparent. When a browser does not support a particular capability, the tool reports that limitation rather than pretending a test succeeded.
